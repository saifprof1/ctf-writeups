# City of the Hadith

**Category:** OSINT

## Challenge Description

The challenge provided an interior photograph of a historic religious building along with a handwritten note containing several historical clues.

The objective was to identify the building and city shown in the photograph and then determine the exact historical date associated with the event described in the note.

## Investigation

### 1. Analyzing the Photograph

I first read the case file carefully and noted the visual clues:

- A large prayer hall
- Stained glass
- Low-hung chandeliers
- Painted domes

The note also contained a historical clue about the conquest of Constantinople and mentioned a young sultan who eventually fulfilled the prophecy.

### 2. Visual Search

Since the photograph was the main visual clue, I used **Bing Visual Search** to search for visually similar images.

The initial results indicated that the building was a **mosque**.

I then compared the visual details of the photograph with information from the search results and continued researching the building and its location.

### 3. Historical Research

After narrowing down the location, I used the clues from the case file to identify the historical event.

The note specifically referred to the conquest of Constantinople and a young sultan whose army captured the city.

I then searched historical sources to determine the exact date of the conquest.

### 4. Finding the Exact Date

The final step was to verify the historical date and combine the modern city name with the date according to the required flag format.

## Tools Used

- Bing Visual Search
- Google Search
- Web Browser

## Lessons Learned

This challenge showed how visual clues and historical context can be combined in an OSINT investigation.

The photograph alone was not enough to immediately determine the answer. Using visual search first and then connecting the result with the historical clues from the case file made it possible to narrow down the correct location and event.
